# 出图美术标准（Gemini 深蓝玻璃光效）

一套给 Grok Bot 和程序化出图用的美术提示词与硬规矩。

覆盖：信息图、日报卡、推特复盘、数据海报，以及需要分叉汇合的流程图。

## 怎么用

1. 打开 [PROMPT.md](./PROMPT.md)。
2. 文生图：复制「一句话生成式提示词」，末尾补上你的主题。
3. 程序化 SVG / Canvas：按色板、背景层、排版硬规矩画；流程图再遵守「真流程图」专规。
4. 出图后对照检查清单勾一遍，尤其是内边距、重叠、字号。
